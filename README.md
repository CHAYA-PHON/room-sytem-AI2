# 🏢 SABAIDEE DORMITORY (ระบบบริหารจัดการหอพักสบายดี)

ระบบบริหารจัดการหอพักและออกใบแจ้งหนี้ ค่าน้ำ ค่าไฟ บันทึกมิเตอร์ พร้อมการวิเคราะห์ข้อมูลและเชื่อมต่อ Google Sheets

---

## 💻 วิธีติดตั้งและเปิดใช้งานบนเครื่องคอมพิวเตอร์ (PC / Mac / Linux)

### 1. ความต้องการของระบบ (Prerequisites)
- ติดตั้ง **Node.js** (เวอร์ชัน 18 ขึ้นไป แนะนำเวอร์ชัน LTS)
  - ดาวน์โหลดได้ฟรีที่: [https://nodejs.org/](https://nodejs.org/)

---

### 2. ขั้นตอนการติดตั้งและรันระบบ

1. **แตกไฟล์ ZIP** ที่ดาวน์โหลดมาไว้ในโฟลเดอร์ที่คุณต้องการบนเครื่องคอมพิวเตอร์
2. เปิดโปรแกรม **Terminal** (Mac/Linux) หรือ **Command Prompt / PowerShell** (Windows)
   *(หรือเปิดโฟลเดอร์ด้วย VS Code แล้วเปิด Terminal ใน VS Code)*
3. เข้าไปยังโฟลเดอร์ของโปรเจกต์ เช่น:
   ```bash
   cd sabaidee-dorm-project
   ```
4. ติดตั้งไลบรารีที่จำเป็น:
   ```bash
   npm install
   ```
5. เริ่มต้นรันเซิร์ฟเวอร์สำหรับใช้งาน:
   ```bash
   npm run dev
   ```
6. เมื่อรันสำเร็จ ให้เปิดเว็บเบราว์เซอร์ (Chrome, Edge, Safari) แล้วไปที่:
   ```
   http://localhost:3000
   ```
   คุณจะสามารถเข้าใช้งานระบบบริหารจัดการหอพักได้ทันที!

---

## 🛠 คำสั่งสำคัญอื่น ๆ
- **รันแอปในโหมดทดสอบ/พัฒนา:** `npm run dev`
- **Build สำหรับ Production:** `npm run build`
- **รันเซิร์ฟเวอร์ Production:** `npm start`
